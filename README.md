# Jedním hlasem – návrhy variant

Prototyp nového webu Jedním hlasem: 9 stránek, každá ve 3 variantách (A / B / C) k porovnání před stavbou ve Frameru.
Přepínač variant a seznam stránek jsou vpravo dole.

Stránky: homepage, Články, Článek (šablona, `?slug=`), Autor (šablona, `?id=`), Antisemitismus, O nás, Podpořte nás, Nahlásit incident, Kontakt.

Čisté HTML/CSS/JS bez buildu. Lokálně: `python3 -m http.server 5190`.

Bankovní údaje, popisy dopadu darů a medailony autorů jsou zástupné.
